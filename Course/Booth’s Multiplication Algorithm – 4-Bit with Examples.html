Booth’s Multiplication Algorithm
4-Bit Signed & Unsigned with Step-by-Step Examples

Booth’s Algorithm is a powerful method to multiply signed binary numbers in 2’s complement form. It reduces the number of partial products by encoding the multiplier.

1. Key Features of Booth’s Algorithm

  • Works with signed numbers (2’s complement)
  • Reduces partial products using radix-4 encoding
  • Eliminates strings of 1s in multiplier → faster addition
  • Used in CPUs, DSPs, and hardware multipliers

2. Booth’s Recoding Table (Radix-2)

Current Bit
(Bi)		 Previous Bit
(Bi-1)		 Action Operation on Accumulator
0 0 No operation —
0 1 Add M A ← A + M
1 0 Subtract M A ← A − M
1 1 No operation —
Note: Bi-1 is an implied 0 before the LSB of the multiplier.

3. Registers Used

  • A: Accumulator (holds partial result, 8 bits for 4×4)
  • Q: Multiplier (4 bits)
  • M: Multiplicand (4 bits)
  • Q-1: Extra bit to hold previous LSB
  • Count: Loop counter (4 for 4-bit)

4. Example 1: 3 × (−2) = −6

Inputs:
Multiplicand (M) = 0011 (3)
Multiplier (Q) = 1110 (−2 in 2’s complement)

Step-by-Step Execution

Initial State:
A = 0000 0000, Q = 1110, Q-1 = 0, M = 0011
StepQ0Q-1ActionA (after)Q (after shift)Q-1
1 0 0 No op 0000 0000 0111 0
2 1 0 A ← A − M 1111 1101 1011 1
3 1 1 No op 1111 1101 1101 1
4 1 1 No op 1111 1101 1110 1
Final A|Q = 11111101 1110 → 11111010 = −6 ✓

Arithmetic Shift Right (ASR) preserves sign bit.

5. Example 2: 5 × 3 = 15 (Unsigned)

M = 0101 (5), Q = 0011 (3)

7. Advantages & Disadvantages

ProsCons

8. Verilog Snippet (Booth Step)

// One step of Booth multiplier
case ({Q[0], Q_m1})
    2'b01: A <= A + M;
    2'b10: A <= A - M;
    default: ; // do nothing
endcase
{A, Q, Q_m1} <= {A[7], A, Q}; // Arithmetic shift
