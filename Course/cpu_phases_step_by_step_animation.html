The Three Phases of CPU Instruction Execution: Step-by-Step Animated Examples

The CPU processes instructions in three phases:

  1. Fetch: Retrieve the instruction from memory into the Instruction Register (IR).
  2. Decode: Interpret the instruction, identifying opcode and operands.
  3. Execute: Perform the operation, using ALU for computations or updating registers/PC.

Below are three examples with detailed step-by-step animations. Each phase is highlighted sequentially, with moving elements and labels for clarity. Use the controls to play automatically, step through manually, or restart.

Example 1: ADD R1, R2, R3 (Arithmetic Operation)

Add contents of R2 (5) and R3 (7), store in R1.

Example 2: LOAD R1, [100] (Memory Load)

Load value (42) from memory address 100 into R1.

Example 3: BEQ R1, label (Branch if Equal to Zero)

If R1 == 0, branch to label (update PC to 500).
