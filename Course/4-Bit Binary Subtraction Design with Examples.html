4-Bit Binary Subtraction Design

Complete Hardware Implementation Using Full Adders & 2’s Complement – Step-by-Step Examples

Overview

Binary subtraction is performed using 2’s complement addition. Instead of direct subtraction, we convert the subtrahend to its negative (2’s complement) and add it to the minuend.

Key Principle:
A − B = A + (−B) = A + (2’s complement of B)
This allows reuse of adder circuits for subtraction.

4-Bit Subtractor Architecture

Inputs & Outputs

  • A[3:0]: Minuend (4 bits)
  • B[3:0]: Subtrahend (4 bits)
  • Diff[3:0]: Difference (4 bits)
  • Borrow_out: Final borrow (overflow/underflow flag)

Example 1: 13 − 6 = 7

Inputs:
A = 1101 (13)
B = 0110 (6)

Method 1: Direct Subtraction (Borrow Method)

    1 1 0 1   (13)
  − 0 1 1 0   (6)
  ─────────
    0 1 1 1   (7)

Method 2: 2’s Complement Addition

Step 1: ~B = ~(0110) = 1001
Step 2: 2’s comp B = 1001 + 1 = 1010
Step 3: A + (−B) = 1101 + 1010 = 0111 (7)
Difference = 0111 = 7 Correct!

Example 2: 5 − 9 = −4 (Signed)

A = 0101 (5), B = 1001 (9)

2’s Complement Subtraction

~B = ~(1001) = 0110
2’s comp B = 0110 + 1 = 0111
A + (−B) = 0101 + 0111 = 1100 → −4 in 2’s complement
Result = 1100 = −4 Correct!

Hardware: 4-Bit Subtractor Circuit

Using Full Adders

// Each bit: Diff_i = A_i ⊕ B_i ⊕ Borrow_in
// Borrow_out = (~A_i & B_i) | (~A_i & Borrow_in) | (B_i & Borrow_in)

Control Signal (Sub = 1 for subtract)

B_in_to_adder = B_i ⊕ Sub
Carry_in_0 = Sub  (1 for subtract, 0 for add)

Verilog HDL Code

4-Bit Subtractor using Adder

// 4-bit Subtractor (A - B)
module subtractor_4bit (
    input  [3:0] A, B,
    input  sub,           // 1 = subtract, 0 = add
    output [3:0] Diff,
    output Borrow_out
);

    wire [3:0] B_comp;
    wire c0, c1, c2, c3;

    // XOR B with sub control
    assign B_comp = B ^ {4{sub}};

    // Carry-in = sub (1 for subtract)
    assign c0 = sub;

    // Ripple carry using full adders
    full_adder fa0 (.a(A[0]), .b(B_comp[0]), .cin(c0),       .sum(Diff[0]), .cout(c1));
    full_adder fa1 (.a(A[1]), .b(B_comp[1]), .cin(c1),       .sum(Diff[1]), .cout(c2));
    full_adder fa2 (.a(A[2]), .b(B_comp[2]), .cin(c2),       .sum(Diff[2]), .cout(c3));
    full_adder fa3 (.a(A[3]), .b(B_comp[3]), .cin(c3),       .sum(Diff[3]), .cout(Borrow_out));

endmodule
