Booth’s Multiplication Algorithm

Efficient Signed Binary Multiplication Using Recoding Technique

Introduction

Booth’s Algorithm is a multiplication technique that reduces the number of partial products by recoding the multiplier. It is particularly effective for signed binary numbers in 2’s complement form and handles strings of 1s efficiently.

Invented by: Andrew Donald Booth in 1951
Key Advantage: Average of only 1 addition/subtraction per 2 bits (vs 1 per bit in standard method)

Core Concept: Recoding Table

The algorithm examines two bits at a time: current bit (Q₀) and previous bit (Q₋₁).

Q₀ Q₋₁ Action Operation Meaning
0 0 No operation — End of 0s string
0 1 Add M A ← A + M Start of 1s string
1 0 Subtract M A ← A − M End of 1s string
1 1 No operation — Middle of 1s string
Q₋₁ is initially 0. After each step, the entire A-Q-Q₋₁ register is arithmetically shifted right (ASR preserves sign bit).

Registers Used (for n-bit multiplication)

A (Accumulator)
2n bits, holds partial product
Q (Multiplier)
n bits, initially holds multiplier
M (Multiplicand)
n bits, fixed during computation
Q₋₁
1 bit, previous LSB of Q
Count
n cycles

Example 1: 7 × (−3) = −21

Inputs:
M = 0111 (7)
Q = 1101 (−3 in 2’s complement)

Initial Setup:
A = 0000 0000, Q = 1101, Q₋₁ = 0, M = 0111
Cycle Q₀ Q₋₁ Action A (after op) A Q Q₋₁ (after ASR)
1 1 0 A ← A − M 1001 1100 1110 1
2 0 1 A ← A + M 0000 0000 0111 0
3 1 0 A ← A − M 1001 1100 1011 1
4 1 1 No op 1100 1110 0101 1
Final Product = 11100101 1 → 11101011 = −21 (Correct!)

Example 2: (−5) × 4 = −20

M = 1011 (−5), Q = 0100 (4)

Cycle Q₀ Q₋₁ Action A A|Q|Q₋₁ (after ASR)
Init — — 00000000 00000000 0100 0
1 0 0 No op 00000000 00000000 0010 0
2 0 0 No op 00000000 00000000 0001 0
3 1 0 A ← A − M 0101 0010 1000 1
4 0 1 A ← A + M 0000 0000 0100 0
Product = 00000100 → 11101100 = −20 (Correct!)

Algorithm Flowchart (Pseudocode)

BOOTH_MULTIPLY(M, Q, n):
    A = 0 (2n bits)
    Q_n-1 = 0
    for i = 1 to n:
        if Q[0..1] == "01":
            A = A + M
        else if Q[0..1] == "10":
            A = A - M
        // Arithmetic Shift Right
        {A, Q, Q_n-1} = ASR({A, Q, Q_n-1})
    return {A, Q}

// Booth multiplier step
always @(*) begin
    case ({Q[0], Q_m1})
        2'b01: A_next = A + M;
        2'b10: A_next = A - M;
        default: A_next = A;
    endcase
end
