4-Bit Binary Divider Design Non-Restoring Algorithm

Hardware Implementation • Step-by-Step Examples • Interactive Simulation

1. Overview

A 4-bit binary divider performs integer division on two binary numbers:

  • Dividend: 4-bit (0 to 15)
  • Divisor: 1 to 4 bits (1 to 15, non-zero)
  • Output: 4-bit Quotient + 4-bit Remainder

Uses Non-Restoring Division — efficient for hardware, avoids full restoration on every negative result.

Registers: A (remainder), Q (quotient), M (divisor)
Operations: Shift left (AQ), Subtract (A-M), Conditional Add (restore)

3. Non-Restoring Division Algorithm

  1. Initialize: A = 0, Q = Dividend, M = Divisor
  2. Repeat 4 times (for 4-bit):
    1. Left shift [A:Q] by 1 bit
    2. A ← A - M
    3. If A ≥ 0 → Q₀ = 1
      If A < 0 → Q₀ = 0, then A ← A + M (restore)
  3. Final: Q = Quotient, A = Remainder
Advantage: Only adds back M when needed → fewer operations than restoring method.
