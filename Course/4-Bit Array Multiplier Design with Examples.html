4-Bit Array Multiplier Design

Complete Hardware Implementation Using AND Gates & Full Adders – Step-by-Step with Examples

Overview

The Array Multiplier (also called Braun Multiplier) is a combinational logic circuit that multiplies two binary numbers using a grid of AND gates for partial products and full adders for summation.

Key Features:
• Regular, repeatable structure → Easy to layout in VLSI
• Uses only AND gates and full/half adders
• Critical path: ~6 × T_FA (Full Adder delay)
• Ideal for teaching and ASIC implementation

Architecture: 4×4 Array Multiplier

Inputs & Outputs

  • A[3:0]: Multiplicand (4 bits)
  • B[3:0]: Multiplier (4 bits)
  • P[7:0]: Product (8 bits)

Gate-Level Implementation

Full Adder (FA) Logic

// Full Adder
Sum = A ⊕ B ⊕ C_in
Carry = (A&B) | (B&C_in) | (A&C_in)

Half Adder (HA) Logic

// Half Adder
Sum = A ⊕ B
Carry = A & B

Critical Path

Longest path: P0 → FA → FA → FA → FA → FA → P7 → 6 Full Adders

Verilog HDL Code

Structural 4-Bit Array Multiplier

// 4-bit Array Multiplier
module array_multiplier_4bit (
    input  [3:0] A, B,
    output [7:0] P
);

    // Partial products
    wire [3:0] pp[3:0];
    genvar i, j;
    generate
        for (i = 0; i < 4; i = i + 1) begin : pp_gen
            for (j = 0; j < 4; j = j + 1) begin
                assign pp[i][j] = A[i] & B[j];
            end
        end
    endgenerate

    // Intermediate sums and carries
    wire [7:0] sum0, sum1, sum2;
    wire [7:0] carry0, carry1, carry2;

    // Row 0: PP0 + PP1<<1
    assign sum0 = {4'b0, pp[0]} + {3'b0, pp[1], 1'b0};

    // Row 1: sum0 + PP2<<2
    assign {carry1, sum1} = sum0 + {2'b0, pp[2], 2'b0};

    // Row 2: sum1 + PP3<<3
    assign {carry2, sum2} = sum1 + {1'b0, pp[3], 3'b0};

    // Final product
    assign P = sum2 + {carry2, 8'b0};

endmodule
