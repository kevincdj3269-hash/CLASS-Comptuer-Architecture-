IEEE 754 Floating-Point Representation

IEEE 754 is the international standard for representing floating-point numbers in binary, widely used in modern computer systems to represent real numbers.

Structure (Single Precision Example)

Field Bits Position Description
Sign Bit 1 bit Bit 31 0 = positive, 1 = negative
Exponent 8 bits Bits 30–23 Biased exponent (Bias = 127)
Mantissa (Significand) 23 bits Bits 22–0 Fractional part after normalization (hidden leading 1)

Value Calculation Formula

Single-precision floating-point value:

(-1)sign × 2(exponent - 127) × (1.mantissa)2

Example 1: Convert 6.5 to IEEE 754 Single Precision

  1. Binary representation: 6.5 = 110.1(2)
  2. Normalize: 1.101 × 22
  3. Sign bit: Positive → 0
  4. Exponent: 2 + 127 = 129 → 10000001(2) → 10000001
  5. Mantissa: 101 → pad to 23 bits → 10100000000000000000000

Full 32-bit representation:

0 | 10000001 | 10100000000000000000000

Hexadecimal: 0x40D00000

Example 2: Convert -2.25 to IEEE 754 Single Precision

  1. 2.25 = 10.01(2) = 1.001 × 21
  2. Sign: Negative → 1
  3. Exponent: 1 + 127 = 128 → 10000000
  4. Mantissa: 001 → 00100000000000000000000
1 | 10000000 | 00100000000000000000000

Hexadecimal: 0xC0100000
