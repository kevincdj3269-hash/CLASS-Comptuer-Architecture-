Operating Mode of Cache Memory

Concept Overview

The basic operation of cache memory relies on the principle of Locality of Reference. When the Central Processing Unit (CPU) needs data, it follows a strict hierarchy:

  1. Step 1: Cache Check. The CPU checks the fast Cache memory first.
  2. Step 2 (Hit): If data is found (Hit), it is delivered immediately. This is the ideal scenario.
  3. Step 3 (Miss): If data is missing (Miss), the system must fetch it from the slower Main Memory (RAM), copy it to the Cache for future use, and then deliver it to the CPU.
