Cache Memory Mapping Techniques

Interactive step-by-step animations with smooth transitions, and now including real cache hit/miss examples with visual feedback.

Step 1: Introduction to Cache Memory

Cache memory is a small, fast memory that stores copies of frequently used data from main memory. A Cache Hit occurs when requested data is found in cache. A Cache Miss occurs when it's not, requiring a fetch from main memory.

Step 2: Technique 1 - Direct Mapping

Explanation

Each main memory block maps to exactly one cache line using Line Index = (Block Number) mod (Cache Lines).

Example Setup

Main Memory: 64 blocks (0–63) | Cache: 8 lines (0–7) | Block size: 4 words

Cache Hit/Miss Examples

Scenario: Cache line 3 contains Block 11 (from previous access).
Now access Block 11 → HIT
Then access Block 19 (19 mod 8 = 3) → MISS (same line, different block)

Step 3: Technique 2 - Fully Associative Mapping

Explanation

Any block can go to any cache line. Uses full tag comparison. Reduces conflict misses.

Cache Hit/Miss Example

Cache contains: Line 0 → Block 5, Line 1 → Block 12
Access Block 12 → HIT (tag match in Line 1)
Access Block 30 → MISS (no tag match)

Step 4: Technique 3 - 2-Way Set-Associative Mapping

Explanation

Cache divided into sets. Each set has 2 lines (ways). Block maps to set using index, but can go to any way in that set.

Cache Hit/Miss Example

Set 1 contains: Way 0 → Block 9, Way 1 → Block 17
Access Block 17 → HIT (in Set 1, Way 1)
Access Block 25 (25 mod 4 = 1) → MISS (Set 1, no match)
