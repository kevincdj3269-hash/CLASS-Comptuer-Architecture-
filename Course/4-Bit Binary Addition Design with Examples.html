4-Bit Binary Addition Design

Complete Hardware Implementation Using Ripple Carry Adder – Step-by-Step Examples

Overview

Binary addition is the foundation of digital arithmetic. A 4-bit adder adds two 4-bit numbers and produces a 4-bit sum with a carry-out (overflow flag).

Key Features:
• Uses Full Adders (FA) and Half Adders (HA)
• Ripple Carry: Carry propagates from LSB to MSB
• Critical path: 4 × T_FA (Full Adder delay)
• Simple, regular, easy to implement in hardware

4-Bit Ripple Carry Adder Architecture

Inputs & Outputs

  • A[3:0], B[3:0]: Two 4-bit inputs
  • Sum[3:0]: 4-bit result
  • Cout: Carry-out (5th bit)
  • Cin: Carry-in (usually 0)

Verilog HDL Code

4-Bit Ripple Carry Adder

// 4-bit Ripple Carry Adder
module adder_4bit (
    input  [3:0] A, B,
    input  Cin,
    output [3:0] Sum,
    output Cout
);

    wire c1, c2, c3;

    full_adder fa0 (.a(A[0]), .b(B[0]), .cin(Cin),  .sum(Sum[0]), .cout(c1));
    full_adder fa1 (.a(A[1]), .b(B[1]), .cin(c1),   .sum(Sum[1]), .cout(c2));
    full_adder fa2 (.a(A[2]), .b(B[2]), .cin(c2),   .sum(Sum[2]), .cout(c3));
    full_adder fa3 (.a(A[3]), .b(B[3]), .cin(c3),   .sum(Sum[3]), .cout(Cout));

endmodule

// Full Adder Module
module full_adder (
    input a, b, cin,
    output sum, cout
);
    assign sum  = a ^ b ^ cin;
    assign cout = (a & b) | (b & cin) | (a & cin);
endmodule
