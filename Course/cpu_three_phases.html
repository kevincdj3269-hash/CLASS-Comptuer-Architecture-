The Three Phases of CPU Instruction Execution

Phase Name Description
1 Instruction Fetch (IF) Fetch the next instruction from memory (or instruction cache) and load it into the CPU.
2 Instruction Decode (ID) Decode the instruction, identify the operation, and read required registers.
3 Execute (EX) Perform the actual operation: ALU computation, memory access, branch decision, write back result.

Three Real Instruction Examples

Example 1: ADD R1, R2, R3 (R1 ← R2 + R3)

PhaseWhat Happens
FetchCPU fetches the instruction ADD R1, R2, R3 from memory
DecodeDecoder recognizes ADD operation; destination = R1, sources = R2 & R3
ExecuteALU adds R2 + R3 → result is written back to R1 and flags are updated

Example 2: LW R4, 100(R5) (Load Word: R4 ← Memory[R5 + 100])

PhaseWhat Happens
FetchCPU fetches the LW R4, 100(R5) instruction
DecodeRecognizes Load-Word; computes address = R5 + 100, destination = R4
ExecuteIssues memory read → data from address is loaded into R4

Example 3: BEQ R6, R7, label (Branch if R6 == R7)

PhaseWhat Happens
FetchCPU fetches the BEQ R6, R7, label instruction
DecodeRecognizes conditional branch; needs to compare R6 and R7
ExecuteCompares R6 == R7
→ If equal: PC = label address
→ If not equal: PC = PC + 4 (next instruction)

Summary: Every instruction in every CPU (x86, ARM, RISC-V, etc.) goes through exactly these three fundamental phases:
Fetch → Decode → Execute
