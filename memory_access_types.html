Two Types of Memory Access Commands

In computer architecture and assembly language, memory access instructions are fundamentally divided into two categories based on the direction of data transfer:

1. Load (Read from Memory → CPU)

The CPU fetches data from main memory (RAM) and places it into a register or another location.

  • Purpose: Bring data into the processor for computation or processing.
  • Common instructions (examples):
  • x86: MOV AX, [BX], MOV EAX, [address]
  • ARM: LDR r0, [r1]
  • MIPS: LW $t0, offset($s0), LB
  • RISC-V: LW x10, offset(x11), LD, LB

2. Store (Write from CPU → Memory)

The CPU writes data from a register (or immediate value) into main memory.

  • Purpose: Save results, update variables, or output data.
  • Common instructions (examples):
  • x86: MOV [BX], AX, MOV [address], EAX
  • ARM: STR r0, [r1]
  • MIPS: SW $t0, offset($s0), SB
  • RISC-V: SW x10, offset(x11), SD, SB

Summary Table

Type Direction Purpose Typical Instructions
Load Memory → CPU Read data into processor MOV (from mem), LDR, LW, LD, LB, etc.
Store CPU → Memory Write data to memory MOV (to mem), STR, SW, SD, SB, etc.

Key Point: Nearly all memory-related instructions in any CPU fall into one of these two categories — you either load data from memory or store data to memory. This is the foundation of the load-store architecture used in modern processors.
