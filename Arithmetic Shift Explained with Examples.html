Arithmetic Shift Explained with Examples

What is Arithmetic Shift?

Arithmetic shift is a bit-shift operation designed for signed integers (two’s complement).
Its key feature: It preserves the sign bit.

  • Arithmetic Left Shift (ASL / SAL / SHL): Shift left, fill with 0 → equivalent to ×2
  • Arithmetic Right Shift (ASR / SAR): Shift right, fill with the original sign bit → equivalent to ÷2 (with floor rounding)

Arithmetic Shift vs Logical Shift

Operation Left Shift Right Shift Fill Preserves Sign?
Arithmetic Shift Fill 0 Fill with sign bit Yes
Logical Shift Fill 0 Always fill 0 No (can change negative → positive)

8-bit Examples (Two’s Complement)

Positive number: +24 = 00011000
Negative number: –24 = 11101000
Operation Original After Shift Decimal Result
Arithmetic Left Shift ×1 (×2) +24 = 00011000 → 00110000 +48
Arithmetic Left Shift ×1 –24 = 11101000 → 11010000 –48
Arithmetic Right Shift ×1 (÷2) +25 = 00011001 → 00001100 +12
Arithmetic Right Shift ×1 –25 = 11100111 → 11110011 –13 (sign bit copied)
Arithmetic Right Shift ×2 (÷4) –88 = 10101000 → 11101010 –22

Critical Difference: Arithmetic vs Logical Right Shift

Original Value Arithmetic Right Shift (SAR) Logical Right Shift (SHR)
–8 = 11111000 → 11111100 = –4 (Correct) → 01111100 = +124 (Wrong!)

Rule: When dividing signed integers by powers of 2, always use arithmetic right shift (SAR) — never logical right shift!

Instruction Names in Popular Architectures

  • x86: SHL / SAL (left), SAR (arithmetic right)
  • ARM: ASL, ASR
  • RISC-V: SLL (left), SRA (arithmetic right), SRL (logical right)
  • MIPS: SLL, SRA
Arithmetic Shift in One Sentence:
"Shift left and fill with 0, shift right and fill with the sign bit"

→ Left = multiply by 2  → Right = signed divide by 2 (floor)
