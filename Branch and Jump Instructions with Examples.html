Branch and Jump Instructions

In assembly language, Branch and Jump instructions are used to change the flow of program execution (control flow). They can be conditional or unconditional.

1. Unconditional Jump / Branch

Always changes the program counter (PC) to the target address.

2. Conditional Branch

Jumps only if a certain condition (usually flags) is met.

CMP  r0, r1
BEQ  equal_label
BNE  not_equal
BGT  greater_than
BLT  less_than
B    always          ; unconditional
            
BEQ  $t0, $t1, match
BNE  $t0, $zero, not_zero
SLTI $t2, $t0, 100    ; set $t2=1 if $t0 < 100
BNE  $t2, $zero, less_than_100
J    somewhere
            
BEQ  x10, x11, equal
BNE  x10, x0, not_zero
BLT  x10, x11, less_than      ; signed
BGEU x10, x11, greater_equal_unsigned
JAL  ra, function_call        ; call subroutine
J    loop                     ; pseudo jump

Key Difference:
• In many architectures (ARM, MIPS, RISC-V), "branch" and "jump" are technically the same concept.
• In x86, JMP can jump very far (any address), while short conditional jumps (JE, JNE, etc.) have limited range (±128 bytes).

Classic Example: Infinite Loop + Conditional Exit

; x86 assembly
loop_start:
    INC  EAX
    CMP  EAX, 100
    JNE  loop_start     ; repeat until EAX == 100
    ; exit loop when EAX reaches 100

This simple pattern is used in nearly every program for loops, if-statements, switch, function calls, etc.
